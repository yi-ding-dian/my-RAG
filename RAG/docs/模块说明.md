# 📘 my-RAG 企业知识库问答系统 模块说明

> **模块定位**：一个可私有化部署的 RAG 知识库系统——上传文档 → 解析 → 切块 → 向量化入库 → 检索增强问答，全链路本地化，支持多租户与权限分级
> **入口**：后端 `python -m uvicorn backend.main:app --port 8091`；前端 `cd frontend && npm run dev`（默认 3002）；界面入口为登录后的左侧菜单（问答 / 检索测试 / 知识库 / 统计分析 / 用户管理 / 系统配置 / 外部查询 / 文档管理 / 日志查看）
