# 父子分块（Parent-Child Chunking）原理

> 本文档说明 my-RAG 知识库"父子分块"切块方式的原理、生成流程与检索用法。
> 对应代码：`backend/chunking/splitter.py`（`ParentChildChunker`，对齐 KnowFlow parent_child 语义）

---

## 一、核心思想：两层块

```
普通切块：块 = 等长字符切片（章节被切断、上下文丢失）

父子分块：
┌─────────────────────────────────────────────┐
│ 父块（完整章节，无大小上限）                    │
│   ## 3.2 机器学习                               │
│   整个章节内容……（可能几千字）                  │
│   ┌──────────┐ ┌──────────┐ ┌──────────┐      │
│   │子块1 800字│ │子块2 800字│ │子块3 600字│     │ ← 检索用（小、精准）
│   └──────────┘ └──────────┘ └──────────┘      │
└─────────────────────────────────────────────┘
检索命中子块 → 把整个父块（完整章节）作为上下文给 LLM
```

**一句话**：**子块负责"找得准"，父块负责"答得全"**——检索时用小块命中，回答时带上完整章节，既有精准度又不丢上下文。

---

## 二、生成流程

```
文档全文
  │ ① 找标题边界（Markdown # 1~N 级）+ 表格/代码块保护
  ▼
父块：按标题聚合完整章节
  ├─ 每个标题（≤ parent_split_level 级）开头的完整章节 = 一个父块（无大小上限）
  ├─ 文档头（首个标题前的文本）= 独立父块
  └─ 超长单节（>5 万字符）才按 parent_chunk_size 兜底二次切
  ▼
子块：按标题层级（min(3, parent_split_level)）切成"章节段"
  ├─ 章节段内用 RecursiveChunker（chunk_size + overlap）递归字符切
  ├─ 任何子块不跨章节边界（overlap 只在章节段内部生效）
  └─ 章节段以标题开头 → 段首子块自带标题行（章节归属一目了然）
  ▼
映射：子块的字符区间 → 落在哪个父块 → child_parent_map
```

---

## 三、关键设计点

| 设计 | 原理 |
|---|---|
| **父块无大小上限** | 章节完整性 > 长度控制（`parent_chunk_size` 只是超长兜底上限，不是目标大小） |
| **子块不跨章节** | 子块严格按标题边界断章，块内不混两个章节 |
| **overlap 不跨章** | 重叠只在章节段内部生效，不串章 |
| **表格/代码块保护** | 标题边界与字符切分都避开表格（连续 \| 行）与 ``` 围栏代码块内部，整体归块不切开（超长可整体成块） |
| **连续标题不切** | 直接相邻的标题行（中间无空行/无正文）不各自成段，并入后续内容段，避免纯标题空块 |
| **子块首行带标题** | 章节段以标题行开头 → 段内首个子块自带"## 3.2 xxx"，便于识别章节归属 |
| **归属映射** | 子块 char 区间完整落在父块区间内；仅超长单节兜底的字符级父块边界可能被 overlap 尾巴跨过 → 回退"起始偏移归属" |

## 四、检索用法（retrieval_mode）

```
用户提问
  ↓
检索子块（小、精准，得分高）
  ↓
取子块所在父块（完整章节）
  ↓
父块作为上下文给 LLM 回答
```

**适用场景**：长章节、强上下文依赖的文档（说明书、制度、技术文档）——回答不会因为"切块切断了上下文"而答偏。

---

## 五、参数说明

| 参数 | 含义 | 默认 |
|---|---|---|
| `chunk_size` / `overlap` | 子块大小 / 重叠 | 入库配置 |
| `parent_chunk_size` / `parent_chunk_overlap` | 超长单节兜底切分用（非目标大小） | 1024 / 100 |
| `parent_split_level` | 父块标题层级（1~6） | 2 |
| `retrieval_mode` | 检索模式（子块检索 + 父块上下文） | 入库配置 |

---

## 六、与其他切块方式对比

| 方式 | 块结构 | 特点 |
|---|---|---|
| naive 通用切块 | 等长字符切片 | 简单通用，无结构感知 |
| title 按标题切块 | 每标题一节（可含 Markdown 标题、Setext、包裹式、前导符号等纯文本标题样式） | 章节结构保留，但长章节被整块检索（块大、精度略低） |
| regex 正则切块 | 按自定义正则边界切 | 灵活，适合固定格式文档 |
| **parent_child 父子分块** | **子块（检索）+ 父块（上下文）双层** | 精准度与上下文完整性兼顾，长章节文档首选 |
| qa 问答切块 | 问答对整块 | 仅限规范问答格式文档（问:/答:） |
